계정 삭제

HACKMAN 계정과 데이터를 삭제하는 방법입니다.

앱·웹에서 직접 삭제

  1. 가입할 때 쓴 카카오·Google·GitHub 계정으로 HACKMAN에 로그인합니다. 앱을 지웠어도 웹(hackman.kr)에서 같은 계정으로 로그인하면 됩니다.
  2. 화면 맨 아래 "회원 탈퇴"를 누릅니다.
  3. 확인창에서 동의하면 즉시 삭제됩니다.

로그인할 수 없는 경우

소셜 계정에 더 이상 접근할 수 없다면 gustjr3332@gmail.com에 HACKMAN 아이디와 가입에 쓴 서비스(카카오·Google·GitHub)를 적어 "계정 삭제 요청"을 보내 주세요. 카카오 계정은 이메일 정보가 없어, 아이디·참가한 대회·팀 이름 등으로 본인임을 확인합니다. 확인 후 7일 이내에 삭제하고 회신합니다.

삭제되는 데이터

  • 계정(소셜 로그인 연결 정보, 이메일이 있으면 이메일), 프로필, 팀 참가 기록이 즉시 삭제됩니다.
  • 이미 채점한 심사위원은 결과 보존을 위해 운영자를 통해 처리합니다.
  • 삭제한 데이터는 복구할 수 없습니다.

자세한 내용은 개인정보처리방침을 참고하세요.
